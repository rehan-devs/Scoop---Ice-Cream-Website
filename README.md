# 🍦 SCOÖP

A stunning, award-worthy artisan ice cream shop website with premium animations and interactive 3D elements.

![Next.js](https://img.shields.io/badge/Next.js-14-black)
![TypeScript](https://img.shields.io/badge/TypeScript-5-blue)
![Tailwind CSS](https://img.shields.io/badge/Tailwind-3-38bdf8)
![GSAP](https://img.shields.io/badge/GSAP-3-88ce02)
![Three.js](https://img.shields.io/badge/Three.js-R3F-black)

## ✨ Features

- 🎨 Luxury design with warm, creamy color palette
- 🍨 Interactive 3D ice cream cone (React Three Fiber)
- 🌀 Buttery-smooth scroll animations (GSAP + Lenis)
- ♾️ Infinite carousel with auto-scroll
- 📱 Fully responsive
- ⚡ Optimized performance
- ♿ Accessible

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** GSAP + ScrollTrigger
- **3D:** React Three Fiber + Drei
- **Smooth Scroll:** Lenis

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
